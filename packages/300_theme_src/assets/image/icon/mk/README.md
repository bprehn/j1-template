## Mount Kato Icon Set

This directory stores MK branding assets while preserving all original J1 files.

Current assets:
- favicon.ico
- mk-64x64.png
- mk-256x256.png
- mk-512x512.png
- mk-logo-mark.svg
- mk-wordmark.svg
- mk-social-square.svg
- mk-social-circle.svg

The SVG files are placeholders and can be replaced with final brand artwork
without changing any consuming paths.
